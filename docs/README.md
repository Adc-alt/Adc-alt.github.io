# Aprendizaje

Documentación de **cómo se construyó este sitio**, paso a paso, con el porqué de cada decisión.

No es documentación de referencia (para eso está MDN). Es el registro de lo que hice yo,
en orden, con lo que instalé, lo que consulté y lo que decidí no hacer.

## Convenciones

- Los bloques de comandos son **literales**: se pueden copiar y pegar.
- Cuando digo "consulté X" pongo el enlace real.
- Las decisiones que se podrían haber tomado de otra forma llevan una sección **Alternativa descartada**.
